# ZAPIKI — site officiel
Site statique public de présentation et documentation du lecteur multimédia ZAPIKI.

Hébergement prévu : **GitHub Pages** ; dépôt de l'application Android conservé privé.

## Pages
- Accueil : `index.html`
- Confidentialité : `confidentialite.html`
- Conditions d'utilisation : `conditions.html`
- Contact : `contact.html`

## Publication GitHub Pages
Ouvrir **Settings > Pages** de ce dépôt, sélectionner **Deploy from a branch**, choisir `main` et `/(root)`, puis enregistrer.

URL attendue après activation : https://kama54.github.io/Zapiki-Website/

## Avant une publication large
Vérifier les obligations légales de l'éditeur, notamment l'identité à mentionner et les règles de conservation / suppression réelles. Tester Google OAuth en mode Production. **GitHub Pages n'assure pas automatiquement la vérification du domaine dans Google Auth Platform** ; la validation d'un domaine autorisé peut nécessiter un domaine propre.

Aucun secret OAuth ni aucune clé privée n'est stocké ici.
